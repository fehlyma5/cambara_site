# Landing Page — Cambará Madeireira

Landing page responsiva criada em HTML, CSS e JavaScript puro.

## Estrutura

- `index.html` — página principal
- `css/style.css` — estilos e responsividade
- `js/script.js` — menu mobile, banner rotativo, swipe e interações
- `README.md` — instruções

## Antes de publicar

Substitua no `index.html`:

1. `5595999999999` pelo número real do WhatsApp da Cambará.
2. Os links `youtube.com`, `instagram.com`, `facebook.com` e `tiktok.com` pelos perfis oficiais.
3. As imagens do Unsplash pelas fotos reais da empresa, fachada, estoque, madeiras e produtos.
4. Se desejar, acrescente endereço completo, telefone, horário de funcionamento e Google Maps.

## Como usar

Abra `index.html` no navegador. Não é necessário framework ou servidor para testar.

Para publicar, envie a pasta inteira para sua hospedagem mantendo a estrutura de arquivos.
